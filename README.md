# Repo Demo

## Problem statement

Working with branches across machines is confusing at first: edits made on one computer, in different branches, have to come together in one history.

## Solution

A small demo repository for practising that workflow. The README was edited from a laptop and from different branches (including one branched from another branch), and the changes were brought together, which exercises branching, pushing, pulling and merging between machines.

## Tech stack

Git, GitHub.

## Features

- Edits made from different machines and branches
- A branch created from another branch
- Open-source licence file included

## Future steps

- Add pull-request and conflict-resolution exercises
- Add a CI check on pushes

## Getting started

```bash
git clone https://github.com/SHRI171981/Repo_Demo
cd Repo_Demo
git branch -a
```
